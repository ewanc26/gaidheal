# Gàidheal for VS Code

Syntax highlighting for [Gàidheal](https://github.com/ewanc26/gaidheal),
the esoteric stack-based programming language written in Scottish Gaelic.
Highlights the three mutation forms of every root word, bracketed
comments, numbers, and the `ma`/`mha`/`no`/`cuairt`/`criòch` block
structure.

## Install

Copy or link this folder into `~/.vscode/extensions/vscode-gaidheal/`.
